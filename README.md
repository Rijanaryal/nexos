# NEXORA

An interactive digital universe for projects, experiments, ideas and code.

## Stack

Next.js · React · TypeScript · Three.js · Node.js · Python/FastAPI · SQL

## Start

```bash
npm install
npm run dev
```

Open http://localhost:3000
